## Overview

This project implements a deep learning–based **image captioning system** that generates textual descriptions for input images. It is built for self-learning purposes to explore the intersection of **Computer Vision** and **Natural Language Processing** using TensorFlow/Keras.

### Key Features

- ✅ Uses a **pre-trained CNN** (e.g., VGG16/InceptionV3) as a visual feature extractor
- ✅ Employs an **LSTM-based language model** for caption generation
- ✅ Integrates **GloVe 100D** pre-trained word embeddings
- ✅ Follows the **merge model architecture** proposed by Tanti et al. (2017)
- ✅ Trained and evaluated on the **Flickr8K dataset**

## Architecture

This project adopts the **merge model** architecture from Tanti et al. (2017), in which the image features and language sequence features are processed independently and then merged before decoding.

```
┌─────────────────────┐        ┌──────────────────────────┐
│   Input Image       │        │   Input Sequence         │
│   (224×224×3)       │        │   (partial caption)      │
└────────┬────────────┘        └─────────────┬────────────┘
         │                                   │
         ▼                                   ▼
┌─────────────────────┐        ┌──────────────────────────┐
│   Pre-trained CNN   │        │   Embedding Layer        │
│ (VGG16/Inception)   │        │   (GloVe 100D)           │
│ → Feature Vector    │        └─────────────┬────────────┘
└────────┬────────────┘                      │
         │                                   ▼
         ▼                        ┌──────────────────────┐
┌─────────────────────┐          │       LSTM           │
│   Dense Layer       │          └──────────┬───────────┘
│ (image projection)  │                     │
└────────┬────────────┘                     │
         │                                  │
         └──────────────┬───────────────────┘
                        │
                        ▼
              ┌─────────────────┐
              │   Merge Layer   │
              │   (Add / Concat)│
              └────────┬────────┘
                       │
                       ▼
              ┌─────────────────┐
              │  Dense + Softmax│
              │  (Vocab Size)   │
              └─────────────────┘
                       │
                       ▼
               Next Word Prediction
```

### Word Embeddings: GloVe 100D

[GloVe (Global Vectors for Word Representation)](https://nlp.stanford.edu/projects/glove/) pre-trained embeddings are loaded into the Embedding layer, replacing random initialization. This significantly improves generalization, especially on smaller datasets like Flickr8K.

## Methodology

This project follows the **merge model** approach described in:

> Tanti, M., Gatt, A., & Camilleri, K. P. (2017). *What is the Role of Recurrent Neural Networks (RNNs) in an Image Caption Generator?* arXiv:1703.09137

### Key design decisions:
1. **CNN as a frozen feature extractor** — image features are extracted once and cached, not fine-tuned during training.
2. **GloVe embeddings** — the embedding matrix is initialized with GloVe 100D vectors to leverage rich semantic knowledge.
3. **Teacher Forcing** — during training, the ground-truth token at each step is fed as input (not the model's own prediction).
4. **Greedy / Beam Search decoding** — captions are generated token-by-token at inference time.

## Installation & Requirements

### Prerequisites

- Python 3.7+
- TensorFlow ≥ 2.x (GPU not required but recommended)
- NumPy, Pillow, tqdm

### Install Dependencies

```bash
pip install tensorflow numpy pillow tqdm
```

### Download GloVe Word Embeddings

Download the **GloVe 100D** embeddings from Stanford:

```
https://nlp.stanford.edu/projects/glove/
```

Download `glove.6B.zip`, extract it, and place `glove.6B.100d.txt` in the project root or update the path in the config.

## Usage

### Step 1 — Build & Train the Model

```bash
python build_model/builder.py
```

This single script handles the full pipeline: extracting CNN image features, preprocessing and tokenizing captions, loading GloVe embeddings, building the CNN+LSTM model, and training it on the Flickr8K dataset.

### Step 2 — Generate Captions

```bash
python caption_generator.py --image path/to/image.jpg
```

Generates and prints a caption for the given image using the trained model.

## Results & Evaluation

The model is evaluated using **BLEU scores** (Bilingual Evaluation Understudy), a standard metric for image captioning:

| Metric | Score (approx.) |
|--------|----------------|
| BLEU-1 | ~0.55 |
| BLEU-2 | ~0.34 |
| BLEU-3 | ~0.23 |
| BLEU-4 | ~0.13 |

> 📝 Actual scores depend on hyperparameters and training duration. Results shown here are approximate baselines for the Flickr8K + GloVe merge model setup.

## Possible Extensions

| Extension | Description |
|-----------|-------------|
| 🗂️ Larger Dataset | Train on **MS COCO** (118K images) or **Flickr30K** for improved generalization |
| 🔧 Fine-tune CNN | Unfreeze top CNN layers and jointly train with the language model |
| 🤖 Swap CNN Backbone | Try **EfficientNet**, **ResNet50**, or **ViT** instead of VGG16 |
| 🔍 Attention Mechanism | Add **visual attention** (Bahdanau/Luong) to focus on relevant image regions |
| 🚀 Transformer-based | Replace LSTM with a **Transformer decoder** (e.g., GPT-style) |
| 📊 Better Evaluation | Add **CIDEr**, **METEOR**, or **SPICE** metrics alongside BLEU |
| 🌐 Web Demo | Build a **Gradio** or **Streamlit** interface for interactive caption generation |
